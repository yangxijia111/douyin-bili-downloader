这个控制台能做什么

它是 douyin-downloader 的网页可视化端，通过 REST API 驱动同一套后端逻辑。

页签覆盖的项目功能
链接下载视频 / 图文 / 合集 / 音乐 / 主页批量（post·like·mix·music）/ 收藏夹（collect·collectmix）/ 直播 / 短链解析；画质档位；时间范围；内容开关（视频·封面·音乐·头像·JSON）；置顶作品；评论采集；视频转写
任务中心并发任务队列、状态与计数（总/成功/失败/跳过）、失败重试、任务结果追踪
数据发现热搜榜抓取、关键词搜索，均导出 JSONL 快照
下载档案download_manifest.jsonl 清单浏览、SQLite 历史分页与作者 / 标题 / 类型筛选
配置中心并发、限速、重试、代理、命名模板、增量下载、浏览器兜底、通知、服务端参数等全部可编辑项

常用命令

python run.py --serve --serve-port 8000 # 启动本控制台 python run.py -c config.yml # 纯命令行批量下载 python -m tools.cookie_fetcher --config config.yml # 交互式抓取 Cookie
