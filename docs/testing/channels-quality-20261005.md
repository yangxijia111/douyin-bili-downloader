# 视频号画质捕获、选择与下载验证（2026-10-05）

用户目标：捕获平台实际提供的画质档位，选择高画质下载，并用 TRAE.ai「搞懂token和上下文让AI省钱」约53分钟回放做后续在线验收。

## 问题与修复

- 页面运行时捕获原先丢失 `media.spec` 与 `fullUrl/fullURL`，播放器晚到的档位也不一定刷新。现在按白名单克隆档位、宽高、码率与源文件地址；档位变化会重新上报，同一作品的稀疏捕获保留已有档位并更新同档元数据。
- 最高档以前主要使用当前播放 URL。现在统一按完整分辨率短边、面积、码率与大小选择最高可用的 SDR 档；竖屏 `1080×1920` 正确显示1080p。只有一边尺寸时明确显示宽度或高度，不能冒称短边分辨率。
- 使用对应 `fileFormat` 替换或补充 `X-snsvideoflag`，不删其他鉴权参数。`aiohttp` 请求显式采用 `yarl.URL(..., encoded=True)`，防止客户端把 `%2F` 等签名编码改成其他字节。
- 原画只有在视频媒体明确提供有效 `fullUrl/fullURL` 时出现。后端也验证视频 CDN 域名、协议、端口与用户信息，并拒绝图片地址；未捕获源文件地址时不能靠删除 URL 参数宣称原画。
- 捕获列表与微信菜单均展示实际档位。网页逐条选择支持已完成作品重新下载，另有独立的 `channels.quality` 默认画质设置。迟到档位会重算默认选择，用户明确手选则保留。
- 下载、流式解密后用本地 FFmpeg 读取实际分辨率。实际宽或高明显低于所选档位时失败，不登记为高清成功；仅捕获单轴尺寸也会核验。成功时显示并记录真实宽高。
- 重新下载为新文件添加分辨率或序号后缀，保留用户已有视频。整个画质下载过程没有增加重编码。
