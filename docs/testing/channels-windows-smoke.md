## 0. 环境准备

| 项 | 要求 |
| --- | --- |
| 系统 | Windows 10 / 11（x64） |
| 微信 | **PC 版微信（WeChatAppEx.exe，内嵌 Chromium）**，记录版本号 |
| Python | 3.10+（mitmproxy 10+ 要求），已 `pip install -e .[channels]` |
| 依赖 | 直播录制需要 ffmpeg（普通视频下载不需要） |
| 网络 | 微信可正常联网；**关闭**其它 VPN / 加速器 / 代理软件 |

## 1. 验收步骤（逐项打勾）

### A. 启动与基础链路

1. **启动视频号模式**
   - CLI：`python run.py --channels`
   - 或网页控制台「视频号」页 → 启动嗅探
   - [ ] 首次运行弹出 Windows 证书确认框，点「是」后提示「根证书已加入信任存储」
   - [ ] 提示「嗅探代理已启动 127.0.0.1:8899 并接管系统代理」

2. **微信正常联网**
   - [ ] 打开微信（若会话前微信已运行，**先彻底退出再启动**——运行中的
     微信不会读到新的系统代理设置）
   - [ ] 微信聊天 / 搜一搜等非视频号功能正常（证明代理没有破坏普通流量）

3. **打开视频号首页**
   - [ ] 微信左侧进入「视频号」，首页正常加载
   - [ ] 视频自动播放

4. **页面出现下载按钮**
   - [ ] 当前视频的操作按钮区域（点赞/评论那一行）出现绿色的「下载」小
     按钮；找不到该区域时页面右下角出现悬浮「下载」按钮（两种都算通过，
     报告里注明实际出现在哪种位置）

5. **切换视频按钮仍存在**
   - [ ] 上滑/下滑切换 3 次视频，「下载」按钮始终在位（ MutationObserver
     重挂生效）

### B. 首页普通视频 × 2（核心路径）

6. **点击下载（第 1 个视频）**
   - [ ] 点击「下载」→ 出现菜单（下载 / 下载最高画质 / 下载最低画质 /
     下载封面，按当前 feed 能力显示）
   - [ ] 点「下载」→ 按钮显示「准备中…」→「下载中」→「✓ 已完成」

7. **当前视频正确保存**
   - [ ] `Downloaded/` 下出现对应文件（文件名含 `channels_<objectId>`）
   - [ ] Web 控制台「视频号」捕获列表出现该条，状态「已完成」

8. **下载的视频可播放**
   - [ ] 用本地播放器（PotPlayer / VLC）打开：**有画面有声音**（MP4 头
     `ftyp` 自校验通过 = ISAAC64 解密正确）

9. **下载的不是上一条视频**
   - [ ] 播放下载的文件，与微信里当前第 1 个视频内容一致（不是切换前
     的视频）

10. **第二个视频（换画质档）**
    - [ ] 切换到下一个视频，点「下载 → 下载最低画质」
    - [ ] 文件保存成功且可播放（X-snsvideoflag 转码档生效）

### C. 详情页与直播

11. **视频详情页**
    - [ ] 点进某个视频的详情页（或从作者主页进入）
    - [ ] 操作栏/底部出现「下载」按钮，点击下载成功且可播放

12. **直播回放**
    - [ ] 找一个直播回放视频（mediaType=4 的普通加密视频），点「下载」
    - [ ] 保存成功且可播放

13. **正在进行的直播（如当时有）**
    - [ ] 进入直播间，出现「开始录制」按钮
    - [ ] 点击后变「停止录制」；点「停止录制」后 `Downloaded/` 下出现
     部分 `.flv` 文件且可播放
    - [ ] （无进行中直播时填 N/A，用回放覆盖）

### D. 收尾

14. **停止后系统代理恢复**
    - [ ] Ctrl+C（CLI）或点「停止」（Web）后提示「系统代理已还原」
    - [ ] 系统设置 → 网络 → 代理，确认「使用代理服务器」已关闭
    - [ ] 微信刷新页面恢复正常

## 2. 失败分级自查（对照 Web 控制台「嗅探链路诊断」卡片）

诊断卡片展示九级状态链，第一个 ✗ 即断点：

| 断点 | 计数器特征 | 含义与处置 |
| --- | --- | --- |
| 代理连接 ✗ | `proxy_connections = 0` | 微信没有走系统代理：确认微信是在启动嗅探**之后**打开的；检查 VPN/加速器 |
| 目标域命中 ✗ | `proxy_connections > 0` 且 `target_domain_connections = 0` | 有代理流量但没有视频号域：确认进了视频号页面；检查 `channels.intercept_domains` |
| HTML 拦截 ✗ | `html_pages_seen = 0` | 命中了域但没看到页面 HTML：等页面完整加载；反馈微信版本号 |
| 脚本注入 ✗ | `html_pages_seen > 0` 且 `injected_pages = 0` | 页面看到了但注入失败：看服务端日志注入错误，反馈微信版本号 |
| 前端心跳 ✗ | `injected_pages > 0` 且 `frontend_heartbeat = 0` | 脚本写入了但没执行：CSP / 页面结构问题，反馈微信版本号 |
| 页面按钮 ✗ | `frontend_heartbeat > 0` 且 `buttons_created = 0` | 脚本在跑但按钮没挂上：播放视频 1–2 秒或切换一次；反馈微信版本号 |
| Feed 获取 ✗ | `buttons_created > 0` 且 `parsed_feeds = 0` | 按钮在跑但数据捕获规则失效：当前微信版本的数据结构可能变了，**带微信版本号 + 页面类型反馈** |
| 下载成功 ✗ | `parsed_feeds > 0` 但下载失败 | 才进入 CDN / decodeKey / ISAAC64 排查：看捕获列表里的失败原因 |

同时记录「捕获策略」分布（诊断卡片标题行）：`page_network_hook` /
`page_runtime_hook` / `passive_response` 各自的条数——用于判断当前是
哪条策略在供数。

## 4. 已知边界（验收前知晓）

- 微信未登录时视频号页面本身不可用，验收需登录态；
- 「未登录时仅能翻页首页」的限制来自微信服务端，与本工具无关；
- 直播录制依赖本机 ffmpeg；未安装时按钮会提示失败原因；
- 自动下载默认关闭（`channels.auto_download: false`）：刷视频只捕获，
  点按钮才下载。想恢复旧行为在配置里改 `true`。
