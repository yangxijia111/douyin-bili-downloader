# 界面优化与下载流程检查记录

日期：2026-10-03。范围：当前仓库的 Web 控制台、CLI / REST 入口、抖音、哔哩哔哩、微信视频号及 yt-dlp 平台实现。原有未提交修改保留；没有升级或安装依赖。

## 界面变化

- 统一多平台工作台名称与操作文案，提供浅色 / 深色主题；窄屏保留带文字的导航。
- 新建下载以「粘贴链接 → 确认保存方式 → 开始下载」为主流程。评论、附加资源和转写收进可展开选项。
- 从分享文案提取同一行的多个链接，按顺序去重，保留带签名的查询参数；支持其他平台裸域名和 B 站 BV / av 号。
- 根据平台和链接类型显示主页范围、批量数量及日期。批量任务默认先取 20 条，0 表示不限；本次参数分别写入各平台配置段。
- 提交前检查空数量、非整数、负数、日期倒置和收藏范围；不支持的平台 / 内容明确标出。视频号链接提供专用入口。
- 提交过程中冻结参数并禁止重复点击；全部入队后进入任务中心，部分提交失败保留结果。
- 任务中心支持状态筛选、作者 / 链接 / 标题搜索，区分部分失败；清理按钮说明仅移除记录。
- 配置中心分组折叠、提示未保存修改，并防止重新读取时误丢草稿；目录选择会触发修改状态。
- 连接设置支持会话令牌，错误响应显示可读说明；请求超时后恢复操作。弹窗支持 Escape、焦点限制和返回原焦点。

## 已复现并修复的缺陷

| 范围 | 原问题 | 修复后的行为 |
| --- | --- | --- |
| 抖音链接 | 链接含 `modal_id` 时仍取旧路径中的作品 ID；编码参数提取错误 | 优先解析查询参数，下载当前分享的作品 |
| 抖音喜欢列表 | 筛选日期、置顶、媒体类型前截断；重复作品占用数量 | 按唯一且符合条件的作品计算数量，继续翻页补齐 |
| 抖音主页合集 / 音乐 | 混合返回作品和元数据时遗漏容器；用容器数代替作品数 | 合并直接作品与展开的内容，按作品去重和筛选 |
| 抖音分页 | 非相邻游标循环可持续请求重复页 | 已访问过的游标不再次请求 |
| 抖音登录失效 | 合集 / 音乐详情、展开接口和自己的主页吞掉登录异常 | 登录异常透传，让入口处理登录失效与重试 |
| 抖音直播 | HLS 保存播放列表文本也算成功；FLV 没有使用配置代理 | 使用现有 FFmpeg 录制 TS，缺失 FFmpeg 明确失败；透传代理，取消时终止录制并保留已录部分 |
| B 站链接 | 裸域名短链解析与路由不一致；av 链接丢失分 P | 正确归一化，并保留分 P 参数 |
| B 站收藏夹 | 连续失效稿件页导致提前终止，遗漏后续有效视频 | 按原始页面是否重复判断翻页停滞 |
| B 站合并 | 取消任务后 FFmpeg 仍继续运行 | 终止合并子进程并按已有清理策略收尾 |
| yt-dlp | 临时 Cookie 和默认缓存写入用户环境 | Cookie 临时文件放到下载目录并清理，关闭默认缓存 |
| 视频号封面 | 封面下载覆盖视频路径、把视频标记为完成 | 封面与主媒体状态分别处理 |
| 视频号任务 | 立即取消永久停留在排队；统计漏计总数 / 跳过数 | 取消进入终态，可以重试；补全计数 |
| 视频号增量 | 封面、BGM、临时 / 空文件误判为已下载作品 | 仅主媒体文件构成增量完成标识 |
| 视频号图文 | 所有图片失败但 BGM 成功时误报完成 | 主图片失败明确失败，不写成功历史与清单 |
| 入口输入 | 分享文案只取首个链接；无效链接直接排队 | CLI 展开多链接；REST 提供离线批量解析，并校验单任务输入 |
| 参数校验 | 错误数字、日期或对象可进入共享配置；422 反馈难读 | 写入和入队前检查格式，返回可读中文 `message` |
| 后台调度 | 运行中任务可重复重试；立即取消或排队暂停失效；旧队列忽略新的并发限制 | 活跃任务重试返回 409；正确取消与暂停；旧队列遵守当前并发上限 |
| 后台生命周期 | 暂停任务阻碍退出；重试次数 0 失效；参数快照共享；取消进度虚报 100% | 正确退出，保留显式 0，独立保存参数快照，按实际进度展示取消任务 |

## 验证方法与边界

后端使用现有 fixtures、mock API 和本地媒体工具做回归，覆盖单视频、图文、主页发布 / 喜欢 / 收藏 / 合集 / 音乐、直播 / 回放、B 站单视频 / 多 P / UP 主 / 收藏夹 / 合集、视频号下载 / 解密 / 页面注入 / MSE，以及 yt-dlp 的解析、选项、错误和落盘流程。

浏览器使用 `.verify/ui_preview.py` 的本机隔离配置和模拟 executor 检查：多链接识别与去重、跨平台任务入队和完成、搜索 / 状态筛选、日期校验、明暗主题、390px 与 1280px 布局、配置草稿与保存。没有在浏览器中启动微信代理、安装证书或访问真实平台下载接口。

最终命令：

```powershell
.venv\Scripts\python.exe _run_tests.py --out=.verify\pytest-final.txt tests/ --basetemp=.test-tmp/final-all -rs
node --test tests/frontend/*.test.js
.venv\Scripts\python.exe -m ruff check .
git diff --check
```

最终结果：**Python 1399 项通过、1 项跳过，前端 74 项通过；Ruff 与差异空白检查通过。** 原始结果见 `.verify/pytest-final.txt`。跳过项是现有 `test_proxy_validator_parity.py` 对缺少旧导出符号的兼容性测试，初次基线检查也已跳过。依赖弃用警告没有通过升级依赖处理。新增 21 项抖音、30 项服务交互回归，以及对应 B 站 / yt-dlp / 视频号和 19 项控制台测试。

**离线测试通过不等同于真实网站当前可下载。** 本次没有使用实际账号验证每个平台的在线端点、Cookie 有效性、风控、会员内容权限、地区限制或真实电脑微信捕获。这些条件需要在相应账号和网络环境下进行实际下载验证；UI 的链接识别结果只说明平台与格式可识别。
